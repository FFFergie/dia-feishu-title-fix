# Dia 飞书标题修复

**专用于 Dia 浏览器的扩展：自动修复飞书标题，一键关闭所有飞书标签。**

[English](README.md) · [下载安装包](https://github.com/FFFergie/dia-feishu-title-fix/releases/latest) · [反馈问题](https://github.com/FFFergie/dia-feishu-title-fix/issues)

## 解决什么问题

部分飞书页面会在标题前加入不可见的 Unicode 格式字符。在 macOS 的 Dia 1.55.1 中实测：给正常标题添加一个 `U+202C`，侧栏便只显示域名；清理前缀后，文档名称恢复显示。

| 修复前 | 修复后 |
| --- | --- |
| `example.feishu.cn` | `项目笔记 - 飞书云文档` |

扩展在页面加载和标题变化时自动清理前缀，保留可见标题和正文中的组合表情，无需逐个改名。

这是面向 **Dia 浏览器** 的独立兼容性修复，并非 Dia 或飞书官方产品。Dia 内部为什么退回域名显示，尚未确认。

## 在 Dia 中安装

1. 从 [Releases](https://github.com/FFFergie/dia-feishu-title-fix/releases/latest) 下载 `dia-feishu-title-fix-1.1.0.zip`。
2. 解压到一个固定目录。
3. 在 **Dia** 中打开 `dia://extensions`，启用「开发者模式」。
4. 点击「加载未打包的扩展程序」，选择包含 `manifest.json` 的解压目录。
5. 刷新安装前已经打开的飞书文档标签。

之后新打开的匹配页面会自动修复。请保留解压目录，浏览器从这里加载扩展。当前通过未打包扩展分发，没有上架应用商店，也不会自动更新。

从源码安装时，选择仓库的 `extension/` 目录。更新时，用新版文件替换安装目录中的文件，在 Dia 扩展管理页点击该扩展的重新加载按钮，再刷新文档。卸载时移除 **Dia Feishu Title Fix**。

## 一键关闭飞书标签

从 Dia 工具栏打开插件。首次点击「启用一键关闭」，允许访问列出的飞书/Lark 站点。授权本身不会关闭标签。之后按钮显示匹配数量，点击「关闭全部飞书标签（N）」即可执行。

范围是**当前浏览器配置的所有窗口，包含固定标签**。匹配以下 HTTPS 域名及其子域：`feishu.cn`、`feishu.link`、`feishuapp.com`、`larkoffice.com`、`larksuite.com`，涵盖这些站点上的文档、审批、管理后台和应用。不会跨浏览器配置操作，不会自动关闭新页面，也不会仅凭标题含有“飞书”就关闭其他网站。关闭前请保存未完成的编辑；关闭的页面可以从浏览器历史记录重新打开。

## 范围与隐私

- 自动标题修复仍仅覆盖 `*.feishu.cn` 的 HTTPS 文档，路径为 `/base/`、`/docx/`、`/docs/`、`/wiki/`、`/sheets/`、`/slides/`。
- 标题修复只改变本机页面标题，不修改云端文档。
- 批量关闭首次使用时申请上述五个域名的**可选站点权限**。拒绝授权不影响标题修复；可以在 Dia 扩展设置中撤回权限。
- 不申请全站 `tabs` 权限；不发送网络请求、不采集或保存数据、无后台进程、第三方依赖与远程代码。可选站点权限允许读取匹配标签的网址、标题并访问对应站点；批量操作实际只使用标签信息与标签 ID。
- 不覆盖其他网站或浏览器配置；新增 Lark/应用域名仅用于批量关闭，不增加标题清理脚本的运行范围。

## 验证范围

标题清理逻辑在 macOS、Dia 1.55.1 和飞书多维表格页面上通过实测，覆盖新开页面、安装后刷新和动态标题变化。实测版本只匹配一个租户；公开版本沿用相同清理逻辑，将匹配范围扩展到飞书子域名。

自动检查覆盖前缀清理、后续标题变化、重复回调收敛、文字及组合表情保留、空标题、精确域名匹配、多窗口选择、权限允许/拒绝、无匹配标签、关闭结果和安装包内容。这些是单元与打包检查，不代表所有浏览器场景都通过实测。其他租户、所有文档类型、其他 Dia 版本、浏览器重启和 Windows 尚未逐项验证。

## 开发与发布

需要 Node.js 22+ 和 Python 3，无需安装依赖。

- `npm test`：运行单元与打包检查。
- `npm run check`：检查脚本语法。
- `npm run package`：在 `dist/` 生成安装包。

GitHub Actions 会检查提交与 PR。推送与扩展版本一致的 `vX.Y.Z` 标签后，自动检查、打包并发布 GitHub Release。贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
